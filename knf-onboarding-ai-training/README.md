# 한전원자력연료 신입직원 입문교육 교재 (세로형)

생성형 AI 스마트워크 & AI 활용 보고서 작성 — 세로(Portrait) 발표/배포용 교재(워크북).

## 개요

| 항목 | 내용 |
|------|------|
| 일시 | 2026. 7. 8.(수) 13:00 ~ 18:00 (총 5H) |
| 대상 | 신입직원 107명 |
| Part 1 | 생성형 AI 스마트워크 (13~16시) — 제미나이 · 노트북LM · AI 스튜디오, **모바일 실습** |
| Part 2 | AI 활용 보고서 작성 (16~18시) — 보고 기본·기획력 + **전지·매직 조별 실습** |

## 구성 (총 30슬라이드, 7.5″ × 10.83″ 세로)

- **표지 / 과정 안내(5시간 여정)**
- **Part 1** 제미나이(시작·이미지·영상/음악·캔버스·웹앱 만들기·프롬프트 6원칙) → 모바일 실습 ① → 노트북LM(시작·6대 기능·실전 프롬프트) → 모바일 실습 ② → 딥리서치(제미나이·노트북LM) → AI 스튜디오 → Part 1 정리·체크리스트
- **Part 2** 왜 보고인가 → 3원칙·두괄식(PREP) → 공문서 작성법(행정업무편람) → 공문서 양식 한눈에 보기(목업) → 3단 구조(두문·본문·결문)+표기법 → 원페이지 보고서 → AI 보고서 4단계 워크플로우 → 전지·매직 실습 안내·평가기준 → 미션카드 → 워크시트
- **마무리** 핵심 정리 / 액션플랜·Thank You

원자력 업종 특성을 반영해 **보안 수칙(대외비·미공개 기술자료 미입력, 결과물 검증)** 을 강조했습니다.

## 파일

- `한전원자력연료_신입직원_입문교육_생성형AI_보고서작성.pptx` — 최종 교재 (PowerPoint에서 편집 가능)
- `build_deck.py` — 교재 생성 스크립트 (python-pptx). 재생성: `pip install python-pptx && python3 build_deck.py`

> 본문 폰트는 `맑은 고딕` 기준입니다. 이모지는 PowerPoint(Windows)에서 컬러로 표시됩니다.
