# 보고 스킬 실습 교안 (PPT)

워크북 PDF와 동일한 디자인 시스템을 16:9 **PowerPoint 슬라이드**로 옮긴 발표용 교안.
편집 가능한 `.pptx` 파일입니다. (총 27장)

## 파일
- `보고스킬_실습_교안.pptx` — 완성 슬라이드 (편집 가능)
- `build_ppt.py` — python-pptx 기반 생성 스크립트

## 빌드
```bash
pip3 install python-pptx
python3 build_ppt.py        # → 보고스킬_실습_교안.pptx
```

## 폰트
- 슬라이드 글꼴은 **맑은 고딕(Malgun Gothic)** — 한국어 Windows/PowerPoint 기본 폰트라
  별도 설치 없이 바로 열립니다. 다른 글꼴을 쓰려면 `build_ppt.py` 의 `FONT` 값을 바꾸세요.

## 구성 (27장)
1. 타이틀 · 목차(Agenda)
2. 모듈1 상사의 말 번역하기 — 질문의 기술 (개념·사례·실습·정리)
3. 모듈2 구두 보고 & 과제 프레이밍
4. 모듈3 이메일 보고 & 보고서 보고
5. 모듈4 보고의 자세 — 메신저 vs 플레이어
6. 모듈5 상사 유형 파악 & 맞춤 소통 (4유형·소통법·외전)
7. 자가진단 · 신입의 보고 5원칙 · 클로징
